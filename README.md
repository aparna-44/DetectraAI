# 🚨 Detectra AI – Smishing Detection System

Detectra AI is a machine learning-based system designed to detect SMS and PDF phishing (smishing) attacks in real-time.

## 🔍 Features

- Detects phishing messages using ML (Naive Bayes)
- NLP-based text preprocessing
- Hybrid model (ML + rule-based detection)
- Real-time alerts and classification
- Streamlit web interface

## 🛠 Tech Stack

- Python
- Machine Learning (Naive Bayes)
- NLP
- Streamlit

## 📊 Accuracy

- Achieved 99.1% accuracy on test dataset

## 🚀 How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
